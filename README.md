# css-component-library-archive

> **Archive Notice**: This library is no longer maintained. Preserved for reference.

A lightweight collection of reusable CSS components and SCSS mixins built between 2018–2021.

## What's included

- Flexbox and Grid layout helpers
- Button, card, modal, and form component styles
- SCSS variables and mixins for theming
- Dark mode utilities

## Usage

```bash
npm install   # install devDependencies
npm run build # compile SCSS → CSS
```

## Structure

```
src/
  components/   # Individual component SCSS files
  mixins/       # Reusable SCSS mixins
  variables/    # Theme tokens
  build/        # Compiled output and cached assets
dist/           # Production CSS
```
